## 编译

安装包含中文字体和 TikZ 支持的 TeX Live 或 MacTeX，并安装 `latexmk`。在相应章节目录中使用 XeLaTeX 编译，例如：

```sh
cd 第五章-完善版讲义
latexmk -xelatex -interaction=nonstopmode -halt-on-error 第五章-分析力学讲义-完善版.tex
```

也可以连续运行两至三次 `xelatex`，直到目录和交叉引用稳定。请保留章节内的相对路径：`原图/` 为正文使用的图像，`补充图/`、`题图/`、`解答图/` 为各章实际存在的可编辑 TikZ 文件。部分图形直接写在主文件中。
